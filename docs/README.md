# New Interaction Docs

This directory is the project handoff surface for humans and future agents.

## Recommended Reading Order

1. [`../README.md`](../README.md) - setup, commands, current gestures, and common parameters.
2. [`prd.md`](prd.md) - product positioning, interaction principles, and roadmap.
3. [`architecture.md`](architecture.md) - implementation architecture and data flow.
4. [`runbook.md`](runbook.md) - permissions, verification, and troubleshooting.

## Planning Artifacts

Implementation plans live in `docs/superpowers/plans/`. They capture how major phases were implemented, but they are not the current operational source of truth. Prefer README, architecture, and runbook for present behavior.
